## work/artwork/manual/002_0_0.png

### left heading

Starting the Game

### left introduction

When you launch the game, the screen-size settings appear. Follow the on-screen instructions to adjust them. The title screen then appears. Press any button to open the main menu.

### left subheading

Main Menu

### Start entry

Start the main game.

### Load entry

Resume from a previously saved intermission. Select the data you wish to load.

### Continue entry

Resume from where you previously saved on the map.

### Library entry

View information about the game's characters, units, and other content.

### Download entry

Resume from a previously uploaded save. Select Download to download save data stored on the network.

### left bottom note

Some commands, including Reassign Pilot, Swap Parts, Sub-Order, D-Trader, Rename Squad, and Bonus Chips, are unavailable in Super Robot Wars Z3: Rengoku-hen.

### right heading

Saving

### right introduction

You can save through commands in intermissions and on the map. Each saves different information. Saving to the system's hard disk requires at least 2295 KB of free space.

### intermission save heading

Saving During Intermissions

### intermission save body

Select Save from the intermission menu. To resume from that intermission, select your data through Load on the main menu or Load on the intermission menu.

### upload heading

Uploading During Intermissions

### upload body

Select Network, then Upload, from the intermission menu to store save data on the network. You can store up to three saves. Selecting an occupied slot overwrites its data.

### map save heading

Saving on the Map

### map save body

Select Quick Save from the overall commands to choose where to save your data.

### hard disk heading

System Hard Disk

### hard disk body

Store save data on the system's hard disk. Select Continue from the main menu to resume from the Quick Save data stored there.

### network heading

Network

### network body

Store save data on the network. Data saved here is stored as System Data.

## work/artwork/manual/003_0_0.png

### left heading

Sharing Data with the PlayStation®Vita Version

### left introduction

The PlayStation®3 version of Super Robot Wars Z3: Rengoku-hen can share save data with the PlayStation®Vita version. Upload your save to the network from the PlayStation®3 version, then download it in the PlayStation®Vita version to continue playing there. You can also download data uploaded from the PlayStation®Vita version in the PlayStation®3 version.

### download heading

Download

### main menu heading

Main Menu

### main menu body

Select Download from the main menu to resume from System Data or Stage Data stored on the network.

### intermission heading

Intermission

### intermission body

Select Network, then Download, during an intermission to resume from Stage Data stored on the network.

### right heading

Clear Data

### clear data paragraph 1

After completing the game, you can save Clear Data and System Data following the ending.

### clear data paragraph 2

Keep System Data recording your clear status on the system's hard disk, or store it on the network by selecting Quick Save from the overall map commands, then Upload to Network. This allows you to receive a Link Bonus in Super Robot Wars Z3: Tengoku-hen.
