# Release 0.1.1 validation

Release 0.1.1 packages local Rengoku-hen build 018 for NPJB00689 as a
whole-PKG xdelta. Detailed evidence is separate from the player release page.

## Package and patch checks

- The original package remains unchanged. All 77 rebuilt package members
  match build 018; three focused package layout/encryption tests pass.
- The release builder decodes the complete delta and verifies the target hash.
- The live public Retro Trans catalog recognizes the original and selects
  0.1.1 for Latest, Next version only and the specific version route.
- Actual public patch download/application and the documented xdelta3 -d -s
  command produce the expected 721,946,688-byte English PKG, SHA-256
  `dc570db31edda1928885ed5647e6a962f88e847eb309bcd2119978202ef39f3a`.
- All six public assets have checked sizes/hashes. Documentation changes
  do not replace any patch, manifest, target or tag identity.

Evidence: [round trip](../releases/0.1.1-validation.json),
[package/native installation](../releases/0.1.1-packaging-validation.json),
[public catalog/download/application](../releases/0.1.1-public-download-validation.json).
DeltaPatcher settings and output naming were checked against upstream source;
its GUI was not used for an independent runtime test.

## Native RPCS3 installation

An isolated RPCS3 0.0.42-20018 installation produced all 77 expected files.
RPCS3 natively decrypts stage SDAT during package installation; the resulting
1,248,500-byte plaintext matches the independently verified build-018 stage,
SHA-256 `06e21b41ac0f21db9fc9ae56a98ccb4aa1e86acbe420fda3c47fc9cc5994b8c1`.
The headless process reports an assertion during teardown (exit 3221226505).
File identity checks pass, but this is not a clean process-exit or gameplay pass.

The package preserves unchanged encrypted payload and replaces/appends changed
entries. Invalid authentication blocks are cleared. It targets RPCS3 only,
not a signed retail or CFW/HEN installer. Physical PS3 execution is unverified.
No user's installed game, save, license or original package was changed.

## Build and translation limits

Recorded build-018 checks comprise 118 tests, 173 archive-member readbacks
and three offline RPCS3 format checks. These are independent from package
validation and do not establish in-game appearance or complete proofreading.
Remaining work includes independent story meaning review, four story flags,
54 battle notes, 97 context/spelling flags, 45 longer subtitle entries and
166 artwork/manual blocks. Gameplay confirmation of this exact release is pending.

## Source provenance

The manifest's source commit identifies public packaging/tools and unchanged
English exports. Build 018 predates Git; its historical build commit is unknown.

`819cf17905618a2d14b2a857fbed43e85fb55efbca1389c40ae3c8e550fca4b5`.
The release tag keeps its existing identity. Current player release notes and
this detailed validation document are maintained on the main branch.
