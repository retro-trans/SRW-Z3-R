# 0.1.2 — Translation and layout corrections

English translation patch for **Super Robot Taisen Z3: Rengoku-hen** on PS3
(**NPJB00689**, Japanese digital release).

This update includes local build **022**, addressing translation and screen
issues reported while testing 0.1.1. The public output remains an **RPCS3-only
PKG**. A separately verified local CFW debug PKG candidate is not distributed;
its whole-package delta would embed the entire game. Corrected screens still
need gameplay confirmation. 0.1.1 remains the first public release.

### Apply

Use [Retro Trans](https://github.com/retro-trans/retro-trans-tools), version
0.5.1 or later. Open **Automatic**, refresh the catalog and select your original
Japanese NPJB00689 PKG or exact English 0.1.1 PKG. Choose **Latest** or
**0.1.2**, save a new output file and keep your source. **Next** from 0.1.1 also
selects this update.

[DeltaPatcher](https://github.com/marco-calautti/DeltaPatcher) or
[xdelta3](https://github.com/jmacd/xdelta) can apply the same patches:

| Your source package | Patch |
| --- | --- |
| Original Japanese PS3 digital release, NPJB00689 | `SRW-Z3-R-NPJB00689-English-0.1.2-RPCS3-from-original.xdelta` |
| Exact English 0.1.1 | `SRW-Z3-R-NPJB00689-English-0.1.1-to-0.1.2-RPCS3.xdelta` |

```text
xdelta3 -d -s "NPJB00689-original.pkg" "SRW-Z3-R-NPJB00689-English-0.1.2-RPCS3-from-original.xdelta" "NPJB00689-English-0.1.2.pkg"
```

In DeltaPatcher enable **Backup original file** and keep **Checksum validation**
enabled. Use the exact source for each route. See the
[installation guide](https://github.com/retro-trans/SRW-Z3-R/blob/main/docs/INSTALL.md)
for the upgrade command and installation steps. Compare rejected inputs with
`BUILD-MANIFEST.json`; keep checksum verification enabled.

### What changed since 0.1.1

- **Skill and Spirit text:** fitted descriptions throughout the categories and
  translated generated skill-level names, including Size Ignore levels.
- **SR conditions and reports:** preserve all 72 native operation strings until
  English display lookup, addressing incomplete/garbled conditions. Repair the
  upgrade-cost refund report and overlapping SR Point/bonus-funds notices.
- **Upgrade bonuses:** fix both Custom Bonus popup variants, wrap all 17 bonus
  effects and fit the Full Upgrade Bonus selector captions beside live values.
- **Combat artwork:** English Center/Wide Attack and compatible support/counter
  banners; Maximum Break lettering follows the requested Z3 translation.
- **Dialogue and terminology:** fix ZONE/Aim keyword spaces, longer dialogue,
  Tiamat's **Daimon** reference and **Asakim Dowin**. Correct the ending line
  about travel becoming possible between the two Earths.
- **Credits:** measure and align all 333 text rows without dropping or
  abbreviating names; retain scroll commands and timing.
- **Distribution:** original and exact 0.1.1 upgrade routes, with whole-output
  hashes and Retro Trans, DeltaPatcher and xdelta3 support.

Earlier title, menu and battle layout corrections are retained. Seventeen
focused regressions, archive readbacks, three offline decryption checks, package
member checks and all 77 installed file hashes passed. These are
file/layout checks, not gameplay acceptance. See the
[validation notes](https://github.com/retro-trans/SRW-Z3-R/blob/main/docs/validation/0.1.2.md).

### PS3 and RPCS3 compatibility

The public package has modified content and cleared authentication. It is
**RPCS3-only**, not Sony retail-signed or a CFW/HEN installer. Physical PS3 boot
is unverified. The separately verified local build022 CFW debug package stays
private because its whole-package xdelta contains the complete game rather
than reusing source data. Maintainer CFW build tools are included in the source
repository and require the documented private inputs. No full PKG, RAP/RIF or
activation files/tools are distributed.

For RPCS3, close the emulator, back up the installation and use **File > Install
Packages/Raps/Edats**. Keep your matching license. Do not delete
`dev_hdd0/game/NPJB00689` as a cache: it contains this digital game. Preserve
savedata and other games. Fresh-boot and load an in-game save, since emulator
save states can retain earlier code/resources.

Isolated native RPCS3 installation produced all 77 expected files with matching
hashes. Its headless process then reported the known teardown assertion
(3221226505). File extraction passed; clean shutdown and game boot are not
claimed. The corrected screens need playtesting on RPCS3 and PS3.

### What's included

English covers 3,334 story records, 3,575 battle drafts and 5,295 non-dialogue
entries, plus selected translated artwork and build022 corrections. Coverage
does not establish every screen is translated or fully proofread. Four story
flags, 54 battle notes and 97 context/spelling flags remain; independent story
review, 45 longer battle subtitles and 166 artwork/manual blocks need further work.

The release includes **two whole-PKG xdeltas**, `BUILD-MANIFEST.json`,
`VALIDATION.json`, `SHA256SUMS.txt`, `PACKAGING-VALIDATION.json`,
`PACKAGING-SHA256SUMS.txt` and `INSTALL.md`.
No full game or license is distributed. No Vita or Vietnamese build is included.
These patches target Rengoku-hen, not Jigoku-hen.

### How it was translated

AI-assisted drafts are followed by terminology checks, editing and review of
playtesting reports. Community references guide names and terms. Proofreading
and corrections are welcome.
