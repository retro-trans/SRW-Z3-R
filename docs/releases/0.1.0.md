# English 0.1.0 — first public Rengoku-hen test release

English translation patch for **Super Robot Taisen Z3: Rengoku-hen** on PS3,
Japanese digital release **NPJB00689**. This release repackages verified local
**build 018** as twelve xdelta patches. It is a public **prerelease** for
playtesting; the latest layouts and real PS3 execution still need confirmation.

## Apply

Download `SRW-Z3-R-PS3-English-0.1.0-file-patches.zip` and extract it.
Follow the included `INSTALL.md`, using your own pristine NPJB00689 game folder
and a new output directory. Python 3.8+ and xdelta3 are required. Preview first:

```powershell
python apply_release.py --source "D:/Games/NPJB00689-original" --out "D:/Games/NPJB00689-English" --xdelta "D:/Tools/xdelta3.exe"
```

Repeat with `--write` after input verification passes. The installer copies
the original folder, applies all patches, and checks the complete target.
`BUILD-MANIFEST.json` contains exact source/output sizes and SHA-256 hashes.
`SHA256SUMS.txt` verifies downloads. `VALIDATION.json` records the local checks.
Use the matching pristine extraction; these patches reject earlier English
builds and Jigoku-hen. Keep checksum verification enabled.

This release is a directory patch set. It is not compatible with Retro Trans's
whole-image Automatic mode. No ISO/PKG route is advertised.

## What's included

- English story dialogue: 3,334 records; independent story meaning review
  remains pending, with four review flags.
- Battle captions: 3,575 drafts covering 5,113 occurrences; independent meaning
  review completed, with 54 retained notes.
- Non-dialogue: 5,295 entries covering 9,177 occurrences, including pilot/mech/
  weapon names, library/glossary, menu/mission text, Spirits and skills;
  97 context/spelling flags remain.
- English title artwork, five Library buttons, Scenario Chart, chapter titles
  and the Intermission heading.
- Dialogue keyword alignment, corrected terrain columns, menu/tab spacing,
  training PP labels, compact stat headings, confirmation alignment, battle
  preview captions, wrapped battle-animation speech and larger Combo popups.

Intermission and Pilot Info now show bare kill totals without Units because
the first-place counter shares that suffix. The 45 longer subtitle entries
and 166 remaining artwork/manual blocks still need insertion/layout work.
Coverage counts do not establish that every possible screen is translated
or fully proofread. No Vita or Vietnamese build is included.

## Compatibility and validation

The recorded local build passed **118 tests**, **173 archive-member readbacks**,
stage encryption round-trip checks and **three independent offline RPCS3
decrypt checks**. All twelve release patches are decoded locally against
their original files and compared with the complete intended target hashes.
The bundled installer is checked against a new complete output folder.

These checks establish patch integrity and format acceptance. Build 018's
new layouts and actual PS3 execution remain unverified in gameplay. Earlier
builds received user gameplay and screenshot reports. See the
[build evidence and remaining checks](../build_status.md).

RPCS3 uses your matching original game/license setup; no RAP is included.
Close RPCS3 and back up your game/saves before changing installations.
Boot the new folder and load an in-game save. Emulator save states can retain
old code and assets. Physical PS3 requires a matching activated installation
and compatible modified setup supporting fake SELF. No blanket CFW/HEN
compatibility is claimed; stock firmware is not supported.

## Sources and contribution

This first patch packages a historical local build created before Git
initialization. The manifest records its actual build-report digest and
binary identities; it does not invent a historical source commit. The public
repository contains the reviewed English snapshot and project-owned tools.
Original script fields, game binaries, fonts, license data and local tools
are excluded. A fresh clone still needs local licensed/source inputs to build.

AI-assisted drafts are followed by terminology checks, editing and playtesting.
The [Jigoku-hen project](https://github.com/retro-trans/SRW-Z3) supplied glossary
and tooling references. Thanks to everyone reporting translation and layout
problems. [Report issues](https://github.com/retro-trans/SRW-Z3-R/issues) with
the version, platform, affected screen and a screenshot.

GitHub's **Source code (zip)** contains project sources. Download the release
patch ZIP and apply it to a game you own. No complete game image or extracted
game files are distributed.
