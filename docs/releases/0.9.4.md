# 0.9.4 — Battle captions, menu fixes and title credit

English translation patch for **Super Robot Taisen Z3: Rengoku-hen** on PS3
(**NPJB00689**, Japanese digital release).

This release contains local **build032**, with corrections made after public
0.9.0. The patched PKG is **RPCS3-only**. Corrected screens still need in-game
confirmation. **0.1.1 remains the first public release.**

### Apply

Use [Retro Trans](https://github.com/retro-trans/retro-trans-tools) **0.5.1 or
later**. Open **Automatic**, refresh the catalog, select the original Japanese
PKG or exact English 0.9.0 PKG, then choose **Latest** or **0.9.4** and save a
new output. From 0.9.0, **Next** selects 0.9.4 after the catalog refresh.
Older public packages can upgrade through the existing release routes.

[DeltaPatcher](https://github.com/marco-calautti/DeltaPatcher) and
[xdelta3](https://github.com/jmacd/xdelta) can apply the same patches:

| Your source package | Patch |
| --- | --- |
| Original Japanese NPJB00689 PKG | `SRW-Z3-R-NPJB00689-English-0.9.4-RPCS3-from-original.xdelta` |
| Exact English public 0.9.0 PKG | `SRW-Z3-R-NPJB00689-English-0.9.0-to-0.9.4-RPCS3.xdelta` |

```text
xdelta3 -d -s "NPJB00689-original.pkg" "SRW-Z3-R-NPJB00689-English-0.9.4-RPCS3-from-original.xdelta" "NPJB00689-English-0.9.4.pkg"
```

In DeltaPatcher enable **Backup original file** and keep **Checksum validation**
enabled. See the [installation guide](https://github.com/retro-trans/SRW-Z3-R/blob/main/docs/INSTALL.md)
for the upgrade command. Keep the source and use a new output filename.

- Original Japanese PKG: **530,382,896 bytes**, SHA-256 `77431599e49115ee14070d11df910ea48d5f3c812883870d9770755d15400307`.
- English public 0.9.0 PKG: **725,958,400 bytes**, SHA-256 `c51b9cb15e37633630830d5f90756921930fe5bb31aeff8add049cffcef2fce8`.
- English 0.9.4 PKG: **725,651,696 bytes**, SHA-256 `4bbe6b10aeee8cfc84069e8e5d25501352fdac98cb2f94ab5eec7863195ffdab`.

`BUILD-MANIFEST.json` records exact inputs and their common output.
`SHA256SUMS.txt` verifies downloads; `VALIDATION.json` records complete patch
decoding. Patch downloads: **195.3 MB** from original or **147.6 MB** from 0.9.0.
Both patches were fully decoded locally and produced the same complete output hash.

All eight public assets were downloaded and verified against their sizes and
SHA-256 digests. The refreshed live Retro Trans catalog recognizes both inputs;
both actual public apply routes produce the complete expected output hash.

### What changed since 0.9.0

- **Battle captions:** prevent long English captions from corrupting portrait
  state or losing sentence endings. Complete captions now use separate drawing
  storage; original battle cues and metadata are retained.
- **Introductions:** restore Mr. Advent and Mr. Blue before Setsuko is told
  she may omit their titles.
- **Menus:** fix overlapping system-config/BGM headings and button hints.
- **Skill and reward text:** translate generated skill +1 through +9 forms
  across all 15 related families, Gold Bar amounts, and the final no-SR Point
  message, including generated numbered forms.
- **Carryover:** fix both reward layouts while retaining percentages, Z Chips
  behavior, upgrade limits, Power Parts limits and exclusions.
- **Title footer:** **v0.9.4** above **github.com/retro-trans** in the
  **bottom-right** corner, updated automatically for each complete build.

Earlier Spirit names, character spellings and condition fixes are retained.
Local versions 0.9.1 through 0.9.3 were test builds, not public releases.

Nine footer/version checks and the preceding 37 focused/regression checks
pass. Packed checks cover 7,290 skill bonus forms, 17 carryover records, two
indexed carryover strings, four final SR Point forms, 5,077 battle captions,
three honorific corrections, 296 condition forms and 36 settings captions.
Archive/overlay/ZIP readbacks, three native offline decryptions and all 77
package/installed file hashes pass. See [validation notes](https://github.com/retro-trans/SRW-Z3-R/blob/main/docs/validation/0.9.4.md).

### PS3 and RPCS3 compatibility

The public output has modified content and cleared authentication. It is
**RPCS3-only**, not Sony retail-signed or a CFW/HEN installer. Physical PS3 boot
is unverified. CFW build tooling requires private original inputs; no debug PKG
or whole-debug-PKG delta is published.

Close RPCS3, back up the installation and saves, then use **File > Install
Packages/Raps/Edats**. Retain your matching license. Preserve savedata and
`dev_hdd0/game/NPJB00689`, which contains this digital game. Fresh-boot and load
an in-game save; emulator save states can retain earlier resources.

The isolated installer extracted all 77 expected files. Its known headless
teardown assertion (3221226505) is separate from successful file
checks. Clean shutdown, gameplay and corrected screen appearance are untested.

### What's included

English sources cover 3,334 story records, 3,575 battle entries and 5,295
non-dialogue entries, with selected translated artwork. Review flags, further
artwork/manual work and in-game confirmation remain. Coverage does not mean
every screen is translated or fully proofread.

Two bare whole-PKG xdeltas, `BUILD-MANIFEST.json`, `VALIDATION.json`,
`SHA256SUMS.txt`, `PACKAGING-VALIDATION.json`, `PACKAGING-SHA256SUMS.txt` and
`INSTALL.md`. No full game, license, Vita build or Vietnamese build is included.
These patches target Rengoku-hen, not Jigoku-hen.
