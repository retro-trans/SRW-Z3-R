# English 0.1.1 — Retro Trans compatible PKG patch

Corrects release packaging for **Super Robot Taisen Z3: Rengoku-hen**, PS3
**NPJB00689**. Translation and layout content remains local **build 018**.
The previous 0.1.0 folder installer did not support Retro Trans Automatic mode.

## Apply

Use [Retro Trans 0.5.1 or later](https://github.com/retro-trans/retro-trans-tools/releases/latest),
refresh its catalog, browse to your original Japanese NPJB00689 PKG, choose
Automatic > Latest or 0.1.1, and save a NEW `.pkg`. Install the result through
RPCS3's File > Install Packages/Raps/Edats. For offline manual patching, download
`SRW-Z3-R-NPJB00689-English-0.1.1-RPCS3.xdelta` and use Apply xdelta.
See [installation instructions](../INSTALL.md).

The original must be 530,382,896 bytes, SHA-256
`77431599e49115ee14070d11df910ea48d5f3c812883870d9770755d15400307`.
The output is 721,946,688 bytes, SHA-256
`dc570db31edda1928885ed5647e6a962f88e847eb309bcd2119978202ef39f3a`.
The standard v1 `BUILD-MANIFEST.json`, bare xdelta, `VALIDATION.json` and
`SHA256SUMS.txt` are compatible with Retro Trans's release/catalog validator.

This is a regular GitHub release so the tool's catalog can discover it;
**the translation remains test content**. Gameplay and physical PS3 checks
are still pending. No new translation/layout fixes are claimed.

## Package compatibility and validation

The complete package is rebuilt locally from the matching original with
unchanged encrypted payload retained. Changed entries are replaced or appended;
all 77 package members match build 018. Original authentication blocks are
cleared: the output is **RPCS3-only**, not a signed retail or CFW/HEN installer.
Only the binary delta is distributed, never the complete package or license.

Native RPCS3 0.0.42-20018 package installation in a new isolated runtime
produced all 77 expected files, including the stage SDAT decrypted to build
018's independently verified plaintext. Its headless process reported a
teardown assertion after extraction (exit 3221226505); this is recorded
separately and is not presented as a clean process exit or gameplay test.
The file checks and whole-PKG patch checks remain independently verifiable.

The original build's 118 tests, 173 rebuilt archive-member readbacks and three
offline RPCS3 checks remain unchanged. Three focused package layout/encryption
tests pass. The release builder decodes the entire PKG delta and verifies its
complete target identity. Detailed publication evidence is included separately.

`source_commit` identifies the public translation/packaging snapshot. Build
018 itself predates Git; this is not a claim about its historical build commit.
The complete build-report hash is retained in detailed validation.

## Coverage and remaining work

Coverage is unchanged from [0.1.0](0.1.0.md): 3,334 story records, 3,575 battle
drafts and 5,295 non-dialogue entries, selected English artwork and build 018's
layout corrections. Four story flags, 54 battle notes and 97 context/spelling
flags remain. Independent story meaning review, 45 longer subtitle entries
and 166 artwork/manual blocks still need work. No exhaustive translation,
physical PS3, CFW/HEN, Vita or Vietnamese support is claimed.

Use your own matching game/license. Do not delete `dev_hdd0/game/NPJB00689`
as a disc cache: this digital title's game is installed there. Keep savedata
and licenses. The original [0.1.0 folder prerelease](https://github.com/retro-trans/SRW-Z3-R/releases/tag/v0.1.0)
is preserved for extracted-folder users.

Report translation/layout issues with a screenshot and version through
[GitHub issues](https://github.com/retro-trans/SRW-Z3-R/issues). Translation is
AI-assisted with terminology checks, editing and playtesting. Jigoku-hen is
a glossary/tooling reference; these patches target only Rengoku-hen.
