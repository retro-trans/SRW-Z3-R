# 0.1.1 — First public release

English translation patch for **Super Robot Taisen Z3: Rengoku-hen** on PS3
(**NPJB00689**, Japanese digital release).

This is the first public release, based on local build 018. The English package
is for RPCS3, and translation review and gameplay confirmation remain in progress.

### Apply

Use [Retro Trans](https://github.com/retro-trans/retro-trans-tools), version
0.5.1 or later. Open **Automatic**, refresh the catalog, and select your original
Japanese NPJB00689 PKG. Choose **Latest** or **0.1.1**, save to a new output
filename, and keep your original package.

[DeltaPatcher](https://github.com/marco-calautti/DeltaPatcher) or
[xdelta3](https://github.com/jmacd/xdelta) can apply the same patch:

| Your source package | Patch |
| --- | --- |
| Original Japanese PS3 digital release, NPJB00689 | `SRW-Z3-R-NPJB00689-English-0.1.1-RPCS3.xdelta` |

```text
xdelta3 -d -s "NPJB00689-original.pkg" "SRW-Z3-R-NPJB00689-English-0.1.1-RPCS3.xdelta" "NPJB00689-English-0.1.1.pkg"
```

Replace the original filename with yours. In DeltaPatcher, enable **Backup
original file** and keep **Checksum validation** enabled. See the
[installation guide](../INSTALL.md) for step-by-step instructions.

The patch requires the exact original package. If verification fails, check
its identity against `BUILD-MANIFEST.json`; keep checksum verification enabled.

- Original Japanese PKG: **530,382,896 bytes**, SHA-256
  `77431599e49115ee14070d11df910ea48d5f3c812883870d9770755d15400307`.
- English 0.1.1 PKG: **721,946,688 bytes**, SHA-256
  `dc570db31edda1928885ed5647e6a962f88e847eb309bcd2119978202ef39f3a`.

`BUILD-MANIFEST.json` records the original, output and patch identities.
`SHA256SUMS.txt` verifies the download; `VALIDATION.json` records the complete
package round trip. The public patch was downloaded and applied through the
live Retro Trans catalog, and the output matched its full hash. The documented
xdelta3 command also produced the same package. Patch download: **191.6 MB**.

### What changed

- **English text:** story dialogue, battle subtitles, pilot/mech/weapon names,
  library entries, menus, Spirit/skill descriptions and mission conditions.
- **Translated artwork:** title screen, Library buttons, Scenario Chart,
  chapter title screens and Intermission heading.
- **Interface corrections:** dialogue and menu alignment, terrain labels,
  stat columns, training tabs, battle captions, confirmation choices and
  Combo popup sizing.
- **Patch distribution:** one whole-PKG xdelta compatible with Retro Trans,
  DeltaPatcher and xdelta3, with original/output hashes and validation files.

Recorded build checks include 118 tests, 173 archive-member readbacks and
three offline RPCS3 format checks. Three focused package tests and all 77
package-member comparisons passed. These checks do not establish gameplay
acceptance; see the [validation notes](../validation/0.1.1.md).

### PS3 and RPCS3 compatibility

Install the generated English PKG through RPCS3's **File > Install
Packages/Raps/Edats**. Close RPCS3 and back up your installation first. Use your
own matching game activation/license; no RAP is supplied. Keep savedata and
other games. **Do not delete `dev_hdd0/game/NPJB00689` as a cache**: that folder
contains this digital game. Restart the game and load an in-game save when
testing, since emulator save states can retain earlier resources.

The package has modified content and cleared authentication blocks. It is
**RPCS3-only**, not a signed retail or CFW/HEN installer. Physical PS3 execution
is unverified. Isolated native RPCS3 installation produced all 77 expected files,
but the headless process reported an assertion during teardown. File checks
passed; a clean process exit and gameplay are not claimed.

Earlier local builds received user gameplay reports. This release's appearance
and runtime behavior still need gameplay confirmation. Include the version and
a screenshot when reporting problems. Details are in the
[validation notes](../validation/0.1.1.md).

### What's included

English covers 3,334 story records, 3,575 battle drafts and 5,295 non-dialogue
entries, plus selected artwork and build 018's layout corrections. Coverage
counts do not establish that every screen is translated or fully proofread.
Four story flags, 54 battle notes and 97 context/spelling flags remain.
Independent story meaning review, 45 longer battle subtitles and 166
artwork/manual blocks still need work.

The release contains one PS3 whole-PKG xdelta and five verification files.
No full package or license is distributed. No Vita or Vietnamese game build
is included. These files target Rengoku-hen, not Jigoku-hen.

### How it was translated

English drafts are AI-assisted, then checked for terminology, edited and
reviewed with playtesting reports. Community references guide names and terms.
Proofreading and corrections are welcome.
