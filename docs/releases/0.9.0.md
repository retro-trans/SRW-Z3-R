# 0.9.0 — Title version, credit and dialogue correction

English translation patch for **Super Robot Taisen Z3: Rengoku-hen** on PS3
(**NPJB00689**, Japanese digital release).

This release contains local **build028**, with corrections made after public
0.1.5. The patched PKG is **RPCS3-only**. Corrected screens still need in-game
confirmation. **0.1.1 remains the first public release.**

### Apply

Use [Retro Trans](https://github.com/retro-trans/retro-trans-tools) **0.5.1 or
later**. Open **Automatic**, refresh the catalog, select the original Japanese
PKG or exact English 0.1.5 PKG, then choose **Latest** or **0.9.0** and save a
new output. From 0.1.5, **Next** selects 0.9.0 after the catalog refresh.
Older public packages can upgrade through the existing release routes.

[DeltaPatcher](https://github.com/marco-calautti/DeltaPatcher) and
[xdelta3](https://github.com/jmacd/xdelta) can apply the same patches:

| Your source package | Patch |
| --- | --- |
| Original Japanese NPJB00689 PKG | `SRW-Z3-R-NPJB00689-English-0.9.0-RPCS3-from-original.xdelta` |
| Exact English public 0.1.5 PKG | `SRW-Z3-R-NPJB00689-English-0.1.5-to-0.9.0-RPCS3.xdelta` |

```text
xdelta3 -d -s "NPJB00689-original.pkg" "SRW-Z3-R-NPJB00689-English-0.9.0-RPCS3-from-original.xdelta" "NPJB00689-English-0.9.0.pkg"
```

In DeltaPatcher enable **Backup original file** and keep **Checksum validation**
enabled. See the [installation guide](https://github.com/retro-trans/SRW-Z3-R/blob/main/docs/INSTALL.md)
for the upgrade command. Keep the source and use a new output filename.

- Original Japanese PKG: **530,382,896 bytes**, SHA-256 `77431599e49115ee14070d11df910ea48d5f3c812883870d9770755d15400307`.
- English public 0.1.5 PKG: **725,958,400 bytes**, SHA-256 `a9e00cbf97a2839cf34d8150b13989db4087bc6b7d9b4243c97823324591c570`.
- English 0.9.0 PKG: **725,958,400 bytes**, SHA-256 `c51b9cb15e37633630830d5f90756921930fe5bb31aeff8add049cffcef2fce8`.

`BUILD-MANIFEST.json` records both exact inputs and their common output.
`SHA256SUMS.txt` checks downloads; `VALIDATION.json` records full patch decoding.
Patch downloads: **195.6 MB** from original or **1.3 MB** from 0.1.5.
Both patches were fully decoded locally and produced the same complete output hash.

### What changed since 0.1.5

- **Title version:** the title screen, build stamp, package proof and release
  now agree on **v0.9.0**, as requested.
- **Title credit placement:** version above **github.com/retro-trans** at the
  **bottom-left**, using Rengoku's own background and small white outlined text.
  Automatic version updates are retained for every complete build.
- **Dialogue correction:** Rand now tells Setsuko to "Cut **him** some slack"
  about Crowe. The surrounding CDS/debt passages were reviewed and retained.

Spirit names (Break/Fury), Crowe Bluest/Elgan Roddick, numbered victory/defeat
conditions, skill/bonus layouts, combat artwork, dialogue wrapping and credits
from 0.1.5 are retained. Local test build 0.1.6 was not a public release.

Nine focused footer/version checks pass, including the explicit 0.9.0
version override and preservation of older packed footers. Archive readbacks, three native
offline decryptions, all 77 package members and all 77 installed file hashes
pass. See [validation notes](https://github.com/retro-trans/SRW-Z3-R/blob/main/docs/validation/0.9.0.md).

### PS3 and RPCS3 compatibility

The public output has modified content and cleared authentication. It is
**RPCS3-only**, not Sony retail-signed or a CFW/HEN installer. Physical PS3 boot
is unverified. CFW build tooling requires private original inputs; no debug PKG
or whole-debug-PKG delta is published.

Close RPCS3, back up the installation and saves, then use **File > Install
Packages/Raps/Edats**. Retain your matching license. Preserve savedata and
`dev_hdd0/game/NPJB00689`, which contains this digital game. Fresh-boot and load
an in-game save; emulator save states can retain earlier resources.

The isolated installer extracted all 77 expected files. Its known headless
teardown assertion (3221226505) is separate from successful file
checks. Clean shutdown, gameplay and corrected screen appearance are untested.

### What's included

English covers 3,334 story records, 3,575 battle drafts and 5,295 non-dialogue
entries, with selected translated artwork. Four story flags, 54 battle notes,
97 non-dialogue context/spelling flags, 45 longer battle subtitles and 166
artwork/manual blocks remain for review or insertion. Coverage does not establish
that every screen is translated or fully proofread.

Two bare whole-PKG xdeltas, `BUILD-MANIFEST.json`, `VALIDATION.json`,
`SHA256SUMS.txt`, `PACKAGING-VALIDATION.json`, `PACKAGING-SHA256SUMS.txt` and
`INSTALL.md`. No full game, license, Vita build or Vietnamese build is included.
These patches target Rengoku-hen, not Jigoku-hen.

### How it was translated

AI-assisted drafts are followed by terminology checks, editing and review of
playtesting reports. Community references guide names and terms. Proofreading
and corrections are welcome.
